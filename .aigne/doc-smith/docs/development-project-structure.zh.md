# 项目结构

本指南概述了 `to-where-cli` 的源代码布局。理解其结构有助于你浏览代码库、做出贡献以及了解不同组件之间的交互方式。

该项目采用关注点分离的组织方式，更易于维护和扩展。

## 总体概览

下图展示了项目的主要组件及其关系。


## 关键目录和文件

下文详细介绍了项目中最核心的目录及其作用。

| 路径            | 描述                                                                                                                                                                     |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/`          | 所有 TypeScript 源代码的根目录。                                                                                                                              |
| `src/cli/`      | 包含命令行的可执行入口点。`index.ts` 文件负责设置命令解析器并执行程序。                     |
| `src/classes/`  | 该目录包含应用的核心逻辑，其中的类用于处理命令实现、配置管理（`SimpleConfig`）和工作进程（`SimpleWorker`）。 |
| `src/protocol/` | 定义作为不同模块契约的 TypeScript 接口。例如，`ConfigProtocol` 和 `WorkerProtocol` 为处理配置或工作任务的类指定了所需的方法。 |
| `src/meta/`     | 包含共享的数据结构和类型定义，如 `Point` 和 `Config`。这些类型在整个应用中统一使用，以确保数据完整性。                |
| `src/index.ts`  | `src` 模块的主入口点，负责聚合和导出必要的类与类型，以供外部使用或打包。                                             |

---

这种结构有助于实现模块化和清晰的关注点分离。理解了项目布局后，你便可以更轻松地定位相关代码。如需了解开发工作流，请继续阅读 [可用脚本](./development-scripts.md) 指南。
