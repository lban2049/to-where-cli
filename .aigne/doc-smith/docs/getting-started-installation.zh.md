# 安装

要开始使用 `to-where-cli`，你需要使用 npm 在你的系统上进行全局安装。全局安装后，你便可以在终端的任何目录中使用 `tw` 命令。

### 前提条件

在继续操作前，请确保你的系统上已安装 [Node.js](https://nodejs.org/) 和 npm (Node Package Manager)。

`to-where-cli` 目前支持以下操作系统：

- macOS
- Windows

### 安装命令

打开你的终端并运行以下命令来安装该软件包：

```shell
npm install -g to-where-cli
```

该命令会从 npm 仓库获取 `to-where-cli` 的最新版本，并进行全局安装。

### 验证安装

安装完成后，你可以通过检查其帮助信息来验证是否安装成功以及 `tw` 命令是否可用：

```shell
tw -h
```

如果安装成功，你将看到可用命令和选项的列表。
