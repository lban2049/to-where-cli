# 安装

在开始创建便捷的别名之前，您需要先安装 `to-where-cli`。该工具通过一个全局 npm 包分发，安装后，您便可以在终端的任何位置使用 `tw` 命令。

## 准备工作

请确保您的系统上已安装 Node.js 和 npm (Node Package Manager)。您可以从 [Node.js 官网](https://nodejs.org/) 下载。

### 支持的平台

请注意，`to-where-cli` 目前支持以下操作系统：

- macOS
- Windows

## 全局安装

要安装此命令行工具，请打开您的终端或命令提示符并执行以下命令：

```shell
npm install -g to-where-cli
```

`-g` 标志用于在您的系统上进行全局安装，这是使 `tw` 命令在整个系统中可用的必要步骤。

## 验证安装

安装完成后，您可以通过运行帮助命令来验证是否安装成功：

```shell
tw -h
```

如果安装成功，您将看到一个包含可用命令和选项的列表。

---
