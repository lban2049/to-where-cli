# 安装

`to-where-cli` 是一个 Node.js 包，可通过 npm (Node Package Manager) 进行安装。在开始之前，请确保您的系统上已安装 Node.js 和 npm。

## 前提条件

- **操作系统**：macOS 或 Windows。

## 全局安装

建议进行全局安装，以便在终端的任何位置都可以使用 `tw` 命令。命令中的 `-g` 标志用于全局安装。

打开您的终端并执行以下命令：

```shell
npm install -g to-where-cli
```

## 验证安装

安装过程完成后，您可以通过运行其帮助命令来验证 `to-where-cli` 是否已正确安装。该命令会列出所有可用选项，并确认该命令行工具（CLI）已在您的系统路径中正确链接。

```shell
tw -h
```

如果安装成功，您将看到帮助信息输出，其中详细说明了命令的用法和选项。
