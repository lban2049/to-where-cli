# 更新日志

本页面记录了 `to-where-cli` 每个版本的变更历史、新功能和错误修复。

## [0.0.23] - 2024-06-06

### 日常维护
- 移除了未使用的代码。

## [0.0.22] - 2024-06-06

### 功能
- 为 `npm` 命令添加了 RunKit 选项。

## [0.0.21] - 2023-09-13

### 功能
- 使用新选项 (`tw npm -c/-d/-v`) 扩展了 `npm` 命令。

## [0.0.20] - 2023-07-11

### 功能
- 添加了对打开指定分支的支持。
- 添加了对打开仓库首次提交的支持。

## [0.0.19] - 2023-05-21

### 功能
- 添加了对打开指定分支的支持。
- 添加了对打开首次提交的支持。

### 文档
- 更新了 `README.md` 和 GitBook 网站文档。

## [0.0.18] - 2023-05-14

### 功能
- 改进了测试覆盖率和实现。

## [0.0.17] - 2023-02-26

### 功能
- 添加了对打开项目 star 页面的支持。
- 添加了使用 `tw rm` 移除多个别名的支持。

## [0.0.16] - 2023-02-10

### 功能
- 添加了对在 npm、百度、谷歌、必应和 GitHub 页面上进行搜索的支持。
- `tw list` 子命令现在接受 `tw ls` 作为简写。

## [0.0.15] - 2023-02-06

### 功能
- `git` 子命令现在支持 Git SSH URL。

## [0.0.14] - 2023-02-03

### 功能
- 添加了使用 `tw git open --pull` 创建拉取请求的支持。

## [0.0.13] - 2023-01-28

### 功能
- 添加了对发布 `to-where-cli` beta 版本的支持。
- 在发布前实现了版本检查。

### 错误修复
- 修复了由 `npx only-allow pnpm` preinstall 脚本引起的 Windows 安装错误。

## [0.0.12] - 2023-01-27

### 错误修复
- 纠正了 `README.md` 文件中的一个错误。

## [0.0.11] - 2023-01-27

### 功能
- 添加了通过 `tw git open --file <path>` 打开指定路径文件的支持。
- 添加了通过 `tw git open -c <hash>` 打开特定提交的支持。

## [0.0.10] - 2023-01-27

### 功能
- 添加了对 Windows 操作系统的支持。
- 添加了对打开各种 Git 页面（包括分支、议题和拉取请求）的支持。
- 实现了访问统计跟踪。
