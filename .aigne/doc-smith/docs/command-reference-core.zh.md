# 核心命令

核心命令是 `to-where-cli` 的基础，提供了管理目录别名的基本工具。这些命令允许你从配置中添加、列出、移除和清除所有别名。

## add

`add` 命令为指定的目录路径创建一个新别名。如果未提供路径，则默认为当前工作目录。如果未提供别名，则使用当前目录的名称。

### 用法

```sh
tw add [alias] [address]
```

### 参数与选项

| 参数 | 描述 | 是否必需 |
|---|---|---|
| `alias` | 目录路径的简短易记名称。 | 否 |
| `address` | 目录的完整或相对路径。 | 否 |
| `-f`, `--force` | 如果已存在同名别名，则覆盖现有别名。 | 否 |

### 示例

**1. 为当前目录创建别名**

如果你位于 `~/projects/my-cool-app`，此命令将创建一个名为 `my-cool-app` 的别名指向该目录。

```sh
tw add
```

**2. 为当前目录创建自定义名称的别名**

此命令将创建一个名为 `cool-app` 的别名指向当前目录。

```sh
tw add cool-app
```

**3. 为特定路径创建别名**

此命令将创建一个名为 `docs` 的别名，指向 `~/documents/work`。

```sh
tw add docs ~/documents/work
```

**4. 覆盖现有别名**

如果别名 `docs` 已存在，此命令会将其路径更新为新位置。

```sh
tw add docs /new/path/to/docs --force
```

## rm

`rm` 命令用于从配置中移除一个或多个别名。

### 用法

```sh
tw rm [alias]
```

### 行为

- **提供别名：** 如果提供一个别名，该命令将移除指定的别名。
- **不提供别名：** 如果在不带别名的情况下运行该命令，它将进入交互模式，并显示所有别名的列表。你可以一次选择多个别名进行移除。

### 参数

| 参数 | 描述 | 是否必需 |
|---|---|---|
| `alias` | 要移除的别名的名称。 | 否 |

### 示例

**1. 移除特定别名**

此命令移除名为 `docs` 的别名。

```sh
tw rm docs
```

**2. 以交互方式移除别名**

不带参数运行该命令将显示一个提示，让你选择要删除的别名。

```sh
tw rm
```

这将触发类似以下的提示，你可以使用箭头键和空格键进行选择：

```
? Select the alias to be deleted233 (Press <space> to select, <a> to toggle all, <i> to invert selection)
❯ ◯ docs => ~/documents/work => 5
  ◯ cool-app => ~/projects/my-cool-app => 12
```

## ls

`ls` 命令（别名为 `list`）用于显示已保存的别名、其对应的路径以及使用次数。

### 用法

```sh
tw ls [alias]
```

### 行为

- **不提供别名：** 列出所有已保存的别名，按访问次数降序排列。
- **提供别名：** 仅显示指定别名的详细信息。

### 参数

| 参数 | 描述 | 是否必需 |
|---|---|---|
| `alias` | 要显示的特定别名的名称。 | 否 |

### 示例

**1. 列出所有别名**

```sh
tw ls
# or
tw list
```

输出格式如下：

```
cool-app => ~/projects/my-cool-app => 12
docs => ~/documents/work => 5
```

**2. 显示特定别名**

此命令仅显示 `docs` 别名的详细信息。

```sh
tw ls docs
```

## clean

`clean` 命令会从配置文件中完全移除所有已保存的别名。此操作不可逆。

### 用法

```sh
tw clean
```

### 选项

为防止意外数据丢失，执行此命令需要一个确认标志。

| 参数 | 描述 | 是否必需 |
|---|---|---|
| `-f`, `--force` | 确认删除所有别名的操作。 | 是 |

### 示例

要永久删除所有别名，请运行：

```sh
tw clean --force
```
