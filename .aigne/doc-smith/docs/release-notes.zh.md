# 发布说明

本节按时间顺序记录了 `to-where-cli` 每个版本中引入的所有更新、新功能、错误修复和改进。这有助于您跟踪更改并了解该工具是如何随着时间演进的。有关该工具的用途和功能的概述，请参阅 [概述](./overview.md) 部分。

## 版本 0.0.23 (2024 年 06 月 06 日)

*   **杂项:** 移除了不必要的代码。

## 版本 0.0.22 (2024 年 06 月 06 日)

*   **功能:** 为 `npm` 命令添加了运行套件选项。

## 版本 0.0.21 (2023 年 09 月 13 日)

*   **功能:** 扩展了 `npm` 命令以支持 `-c`、`-d` 和 `-v` 选项（例如，`tw npm -c/-d/-v`）。

## 版本 0.0.20 (2023 年 07 月 11 日)

*   **功能:** 增加了对打开指定分支的支持。
*   **功能:** 增加了对打开首次提交的支持。

## 版本 0.0.19 (2023 年 05 月 21 日)

*   **功能:** 增加了对打开指定分支的支持。
*   **功能:** 增加了对打开首次提交的支持。
*   **文档:** 更新了 `README.md` 和 GitBook 站点文档。

## 版本 0.0.18 (2023 年 05 月 14 日)

*   **功能:** 改进了测试覆盖率和可靠性。

## 版本 0.0.17 (2023 年 02 月 26 日)

*   **功能:** 增加了对打开项目星标界面的支持。
*   **功能:** 使用 `tw rm` 时支持删除多个别名。

## 版本 0.0.16 (2023 年 02 月 10 日)

*   **功能:** 实现了跨 npm、百度、谷歌、必应和 GitHub 页面的搜索功能。
*   **功能:** `tw list` 子命令现在支持 `tw ls` 缩写。

## 版本 0.0.15 (2023 年 02 月 06 日)

*   **功能:** `git` 子命令现在支持 Git SSH URL。

## 版本 0.0.14 (2023 年 02 月 03 日)

*   **功能:** 增加了使用 `tw git open --pull` 创建拉取请求的支持。

## 版本 0.0.13 (2023 年 01 月 28 日)

*   **功能:** 支持 `to-where-cli` 的 Beta 版本发布。
*   **修复:** 解决了与 `to-where-cli@0.0.12 preinstall: npx only-allow pnpm` 相关的 Windows 安装错误。
*   **功能:** 实现了在发布前进行版本检查。

## 版本 0.0.12 (2023 年 01 月 27 日)

*   **修复:** 纠正了 `README.md` 文件中的一个错误。

## 版本 0.0.11 (2023 年 01 月 27 日)

*   **功能:** 支持通过 `tw git open --file xxx` 打开指定路径的文件。
*   **功能:** 支持通过 `tw git open -c xxx` 打开具有指定哈希值的提交。

## 版本 0.0.10 (2023 年 01 月 27 日)

*   **功能:** 增加了对 Windows 操作系统的支持。
*   **功能:** 支持打开 Git 分支页面、问题列表页面、拉取请求列表页面等。
*   **功能:** 实现了访问统计跟踪。

---

这就是 `to-where-cli` 详细的发布历史。要开始使用最新版本，请参阅 [入门](./getting-started.md) 指南。
