# Release Notes

This section provides a chronological record of all updates, new features, bug fixes, and improvements introduced in each version of `to-where-cli`. This helps you track changes and understand how the tool has evolved over time. For an overview of the tool's purpose and capabilities, see the [Overview](./overview.md) section.

## Version 0.0.23 (June 06, 2024)

*   **Chore:** Removed unnecessary code.

## Version 0.0.22 (June 06, 2024)

*   **Feature:** Added run kit options to the `npm` command.

## Version 0.0.21 (September 13, 2023)

*   **Feature:** Extended the `npm` command to support `-c`, `-d`, and `-v` options (e.g., `tw npm -c/-d/-v`).

## Version 0.0.20 (July 11, 2023)

*   **Feature:** Added support for opening a specified branch.
*   **Feature:** Added support for opening the first commit.

## Version 0.0.19 (May 21, 2023)

*   **Feature:** Added support for opening a specified branch.
*   **Feature:** Added support for opening the first commit.
*   **Docs:** Updated `README.md` and the GitBook site documentation.

## Version 0.0.18 (May 14, 2023)

*   **Feature:** Improved test coverage and reliability.

## Version 0.0.17 (February 26, 2023)

*   **Feature:** Added support for opening the star screen of a project.
*   **Feature:** Enabled removing multiple aliases when using `tw rm`.

## Version 0.0.16 (February 10, 2023)

*   **Feature:** Implemented search functionality across npm, Baidu, Google, Bing, and GitHub pages.
*   **Feature:** The `tw list` subcommand now supports the `tw ls` shorthand.

## Version 0.0.15 (February 06, 2023)

*   **Feature:** The `git` subcommand now works with Git SSH URLs.

## Version 0.0.14 (February 03, 2023)

*   **Feature:** Added support for creating pull requests using `tw git open --pull`.

## Version 0.0.13 (January 28, 2023)

*   **Feature:** Supported the release of beta versions for `to-where-cli`.
*   **Fix:** Resolved a Windows installation error related to `to-where-cli@0.0.12 preinstall: npx only-allow pnpm`.
*   **Feature:** Implemented a version check before releases.

## Version 0.0.12 (January 27, 2023)

*   **Fix:** Corrected an error in the `README.md` file.

## Version 0.0.11 (January 27, 2023)

*   **Feature:** Enabled opening files at a specified path via `tw git open --file xxx`.
*   **Feature:** Enabled opening commits with a specified hash via `tw git open -c xxx`.

## Version 0.0.10 (January 27, 2023)

*   **Feature:** Added support for Windows operating systems.
*   **Feature:** Supported opening Git branch pages, issue list pages, pull request list pages, and similar.
*   **Feature:** Implemented visit statistics tracking.

---

This concludes the detailed release history for `to-where-cli`. To get started with the latest version, refer to the [Getting Started](./getting-started.md) guide.
