# 基本用法

安装 `to-where-cli` 后，你就可以立即开始管理地址别名。本指南将引导你完成基本工作流程：添加新别名、打开其关联地址、列出已保存的别名，以及在不再需要时移除它们。

## 添加别名

若要使用一个易于记忆的名称来保存 URL 或本地文件路径，请使用 `tw add` 命令。该命令的结构为 `tw add <alias> <address>`。

例如，为 GitHub 个人资料 URL 创建一个名为 `home` 的别名：

```shell
tw add home https://github.com/skypesky
```

如果省略别名和地址，该命令将使用当前工作目录作为地址，并使用目录名作为别名。

## 通过别名打开地址

要打开与别名关联的地址，只需运行 `tw` 命令，后跟别名即可。这将在相应的默认应用程序（例如，网页浏览器会打开 URL）中打开该 URL 或路径。

```shell
tw home
```

执行此命令将在你的默认浏览器中打开 `https://github.com/skypesky`。

## 列出别名

要查看所有已保存的别名及其对应的地址，请使用 `tw ls` 命令。`list` 命令是 `ls` 的别名。

```shell
tw ls
```

如果你想查询特定别名的地址，可以将别名作为参数传入：

```shell
tw ls home
```

## 更新别名

要更改与现有别名关联的地址，只需使用相同的别名再次运行 `tw add` 命令即可。新地址将覆盖旧地址。

```shell
# 这会将“home”别名更新为指向一个新的代码仓库
tw add home https://github.com/skypesky/leetcode-for-javascript
```

## 移除别名

要删除不再需要的别名，请使用 `tw rm` 命令，后跟别名。

```shell
tw rm home
```

如果运行 `tw rm` 时未指定别名，该工具将启动交互模式，显示所有别名的列表，并允许你选择一个或多个进行删除。
